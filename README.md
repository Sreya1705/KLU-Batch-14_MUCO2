# Credit Pre-Screening Analysis

## Project Overview

This project focuses on Credit Pre-Screening using data analysis and machine learning techniques. It explores applicant-related data to understand important factors associated with credit screening and supports data-driven insights for the preliminary evaluation of credit applicants.


## Objectives

- Understand and explore the Credit Pre-Screening dataset.
- Perform data preprocessing and exploratory data analysis (EDA).
- Identify important patterns and relationships in the dataset.
- Apply relevant analytical and machine learning techniques.
- Generate meaningful insights to support credit pre-screening decisions.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sreya1705/KLU-Batch-14_MUCO2.git
```

### 2. Navigate to the Project Directory

```bash
cd KLU-Batch-14_MUCO2
```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run the Project

Open `Batch 14_MUC02_KLU_Notebook.ipynb` and execute the cells sequentially.

Ensure that the dataset is available in the appropriate directory before running the notebook.
